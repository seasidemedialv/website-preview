# Website Preview

A lightweight repository for testing and previewing Seaside Media websites.

## Current test

The root contains a responsive static test page built with plain HTML, CSS, and
JavaScript. It has no package dependencies or build step.

## Preview

GitHub Pages publishes every change pushed to `main` using the included GitHub
Actions workflow.

Preview URL:

`https://seasidemedialv.github.io/website-preview/`

## Local use

Open `index.html` directly in a browser, or serve the directory with any static
web server.
